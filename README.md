# 组题工坊

一个无需上传到服务器的浏览器端数学试卷组题工具。教师可以导入一份或多份 PDF，逐页框选题目，统一尺寸后重新排版并导出为 A4 PDF。

## 功能

- 同时导入多份 PDF 试卷
- 页码缩略图和逐页预览
- 鼠标框选任意题目区域
- 已选题目排序、复制、删除
- 每道题单独设置紧凑 / 标准 / 通栏宽度
- A4 横向或纵向、单栏或双栏排版
- 自定义页边距、题目间距、题号和来源
- 浏览器本地生成并下载 PDF，试卷不会上传到服务器

## 本地打开

在本目录运行：

```powershell
pnpm install
pnpm dev
```

然后在浏览器访问 `http://localhost:3000`。

如果只想快速试用，也可以在 `public/studio` 目录启动任意静态文件服务。由于 PDF 渲染使用 Web Worker，不能直接双击 `index.html` 打开。
